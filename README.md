# Скрипт архивации и последующего удаления логов
Этот PowerShell-скрипт предназначен для архивации файлов из указанных директорий с использованием 7-Zip и удаления старых архивов.

## 1. Входные параметры
Скрипт принимает несколько параметров для настройки работы:
1. ```$zip``` (строка):
    * Путь к исполняемому файлу ```7z.exe``` (утилита 7-Zip).
    * По умолчанию: ```"C:\Program Files\7-Zip\7z.exe"```.
2. ```$extenssion``` (строка):
    * Расширение для создаваемых архивов.
    * По умолчанию: ```".7z"```.
3. ```$BackUp_path``` (строка):
    * Путь к первой директории для архивирования.
    * По умолчанию: ```"C:\inetpub\logs\LogFiles\W3SVC1\"```.
4. ```$BackUp_path1``` (строка):
    * Путь ко второй директории для архивирования.
    * По умолчанию: ```"C:\inetpub\logs\LogFiles\W3SVC2\"```.
5. ```$days``` (число):
    * Количество дней, определяющее, какие файлы архивировать.
    * Если файл старше этой даты, он будет добавлен в архив.
    * По умолчанию: ```-1``` (все файлы, созданные ранее текущей даты).
6. ```$backup_days``` (число):
    * Количество дней, определяющее, какие архивы удалять.
    * Если архив старше этой даты, он будет удален.
    * По умолчанию: ```-31``` (удаляются архивы старше 31 дня).

## 2. Функции
### 2.1. ```Archive-file```
Эта функция выполняет архивирование файлов:
* **Аргументы:**
    * ```$file_zip```: Путь к исполняемому файлу ```7z.exe```.
    * ```$file_path```: Путь к директории, в которой находятся файлы для архивирования.
    * ```$file_extenssion```: Расширение для создаваемых архивов (например, ```.7z```).
* **Шаги:**
    1. Получает список всех файлов с расширениями ```.txt``` и ```.log``` в указанной директории (```$file_path```).
    2. Проверяет дату создания каждого файла. Если файл создан ранее, чем ```(Get-Date).AddDays($days)```, он будет архивирован.
    3. Создает архив, используя 7-Zip, с именем, основанным на дате последнего изменения файла.
    4. Удаляет исходный файл после его архивирования.
* **Ключевые параметры для ```7z.exe```:**
    * ```-t7z```: Тип архива (7-Zip).
    * ```-m0=lzma2```: Использование алгоритма сжатия LZMA2.
    * ```-mx=9```: Максимальный уровень сжатия.
    * ```-aoa```: Автоматическая перезапись существующих архивов.
    * ```-mfb=64```: Размер блока сопоставления в байтах.
    * ```-md=32m```: Размер словаря 32 МБ.
    * ```-ms=on```: Включение солидного сжатия.

### 2.2. ```Archive-Remove```
Эта функция удаляет старые архивы:
* **Аргументы:**
    * ```$remove_path```: Путь к директории, где хранятся архивы.
* **Шаги:**
    1. Ищет все архивы с расширением ```.7z``` в указанной директории.
    2. Проверяет дату создания каждого архива. Если архив старше ```(Get-Date).AddDays($backup_days)```, он будет удален.
    3. Удаляет архивы, соответствующие критерию.

## 3. Основной блок
**Архивирование и удаление старых архивов для первой директории**
```powershell
Archive-file $zip $BackUp_path $extenssion
Archive-Remove $BackUp_path
```
* Архивирует файлы из директории ```$BackUp_path```.
* Удаляет старые архивы из той же директории.\
**Архивирование и удаление старых архивов для второй директории**
```powershell
Archive-file $zip $BackUp_path1 $extenssion
Archive-Remove $BackUp_path1
```
* Аналогичные действия выполняются для директории ```$BackUp_path1```.

## 4. Пример вызова скрипта
```powershell
.\ArchiveLogs.ps1 -zip "C:\Program Files\7-Zip\7z.exe" -extenssion ".7z" -BackUp_path "C:\logs\W3SVC1\" -BackUp_path1 "C:\logs\W3SVC2\" -days -7 -backup_days -30
```
* Архивирует файлы старше 7 дней.
* Удаляет архивы старше 30 дней.

## 5. Ожидаемый результат
1. Все файлы ```.txt``` и ```.log```, соответствующие критерию по дате, будут заархивированы.
2. Архивы старше указанного периода времени (```backup_days```) будут удалены.
3. Итоговые архивы будут находиться в директориях ```$BackUp_path``` и ```$BackUp_path1```.

## 6. Примечания
1. Убедитесь, что 7-Zip установлен и путь к ```7z.exe``` указан правильно.
2. Обратите внимание на права доступа к указанным директориям.
3. Если возникают ошибки, проверьте права выполнения PowerShell-скриптов с помощью команды:
```powershell
Set-ExecutionPolicy RemoteSigned
```
